Promo Agent — Privacy Policy

Last updated: 31 October 2026

Promo Agent is a private tool used only by the developer of MyMovies and Vocabulizer (Vlad Kolomiichuk) to publish promotional videos to the developer's own accounts on YouTube and TikTok. It is not offered to other users.

Data we access

When the developer connects an account, the tool receives an access token and basic profile information (account name and ID) for that account only. It uses them solely to upload videos the developer has approved to that same account.

Storage

Tokens are stored only on the developer's own computer and are never shared, sold or sent to third parties. No data about other people is collected.

Removing access

Access can be revoked at any time in the connected platform's settings (Google Account → Security → Third-party access; TikTok → Settings → Security → Manage app permissions), and the local tokens deleted.
